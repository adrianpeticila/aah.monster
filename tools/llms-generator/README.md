# LLMs.txt Generator

A client-side tool that generates a structured `/llms.txt` file for your website. Built for [aah.monster](https://aah.monster).

## What is llms.txt?

AI models and crawlers (like OpenAI's GPTBot, Google Extended, or Anthropic's ClaudeBot) scrape the web to build context. Adding a `/llms.txt` file to the root of your domain acts as an instruction manual for them, similarly to how `robots.txt` works for traditional search engines. It ensures AI models understand exactly what your brand is, what you do, and how they should cite you.

## Features

- **Live Preview:** See your markdown rendered in real-time as you type.
- **Privacy First:** 100% client-side. No data is sent to any server. No API calls.
- **One-Click Download:** Exports the `.txt` file ready to be uploaded to your root directory.

## Live Version

Available at [tools.aah.monster](https://tools.aah.monster) (or your configured subdomain).

## Setup

No setup required. Just open `index.html`.
